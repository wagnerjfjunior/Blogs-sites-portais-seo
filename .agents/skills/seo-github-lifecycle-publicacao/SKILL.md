# GPT4 — SEO - GitHub, lifecycle e publicação

## Procedimento
1. Confirmar repositório, branch base, escopo e autorização.
2. Criar branch e mudança rastreável.
3. Abrir Pull Request e coletar checks.
4. Validar drift, arquivos, reviews e elegibilidade.
5. Publicar somente após autorização explícita.

## Proibições
Não fazer merge, deploy ou publicação sem autorização. Não contornar checks ou proteção de branch.
