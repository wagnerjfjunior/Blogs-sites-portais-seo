# ADR-0001 — Framework canônico dos GPTs

**Status:** aceito

## Decisão
Manter nove especialistas privados, cada um com contrato, skill, manifest Builder, Instructions e testes. GitHub é fonte canônica. O acesso ao GitHub será por Action OpenAPI somente leitura no bootstrap.

## Consequências
A configuração do Builder é manual, mas verificável contra hashes e manifests. Ready e merge permanecem sob autorização humana. SFJM não integra este escopo.
