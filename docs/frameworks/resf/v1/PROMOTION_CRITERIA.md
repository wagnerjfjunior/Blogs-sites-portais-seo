# RESF v1 — Promotion Criteria

Current lifecycle: `CANDIDATE`.

Promotion to `RECOMMENDED` requires, at minimum:

1. provider-local contracts complete and resolvable;
2. normalized patterns and anti-patterns;
3. immutable provenance;
4. structural tests passing;
5. at least one controlled greenfield application;
6. post-implementation revalidation;
7. no unclassified critical contradiction;
8. material gaps explicit;
9. formal Product Authority decision;
10. a dedicated provider lifecycle PR governed by current SFJM gates.

## Current assessment

The current evidence does **not** justify promotion.

- Capri is a high-value reference implementation with observed Google visibility and Gemini citation, but causality is not established.
- Vista Milano is a controlled preview application; production validation and complete post-implementation revalidation are absent.
- Current tracking/dedup, consent enforcement and closed-loop CRM/offline attribution remain consumer/runtime evidence gaps.
- Search-to-Revenue is explicitly outside v1.

`DOCUMENTATION_COMPLETE != RECOMMENDED`

`CAPRI_VISIBILITY != RANKING_CAUSALITY`

`CONTROLLED_PREVIEW != PRODUCTION_REVALIDATION`
