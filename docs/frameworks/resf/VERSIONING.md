# RESF Versioning

`v1 = Search-to-Lead`.

Search-to-Revenue is not an implicit extension of v1. It requires a separately versioned lifecycle with evidence for CRM opportunity/sale feedback, revenue attribution and applicable offline-conversion loops.

Breaking semantic changes to module IDs, contract IDs, adoption schema or lifecycle interpretation require a new framework version or explicit compatibility alias.

Existing canonical paths are preserved whenever possible. Renames require aliases and tests.
